## Refined Requirement

**使用者已定案(2026-07-26):**

- **品質基準:對外提案用** —— 要能拿給客戶看、經得起截圖放大。

**兩者的張力與應對(architect 需正視):** 程序化材質的寫實度天花板低於照片級 PBR 貼圖,但目標是提案品質。因此程序化**不可做得敷衍**:
- 需要真正的 normal map(不只 albedo 換色),表面才有受光起伏。
- 需要細微的非重複變化(噪聲擾動),避免一眼看穿的規律平鋪。
- 展場地板/牆面現實中本就是素面(環氧地坪、拋光石英磚、烤漆板),這是程序化最擅長、與照片貼圖差距最小的題材 —— 應扣著這個方向做,不要嘗試模擬複雜有機紋理(木紋、大理石)。
- 場景整體的寫實度主要由家具承擔(task 4–5 匯入真實模型),本任務只要讓地板/牆/柱「不像塑膠玩具」即可達標。

本任務要求:

## Edge Cases to Handle

- **極大場地(200m)**:貼圖重複次數極高,需確認 texture repeat/wrap 設定與各向異性過濾,避免遠處出現摩爾紋或糊成一片。
- **極小場地**:紋理不可放大到失真(單一磚縫佔滿整個地板)。
- **凹多邊形地板**:UV 映射需在 `ExtrudeGeometry` 的凹多邊形上正確,不可出現拉伸變形或紋理跳接。
- **牆的厚度面**:牆是 `WALL_THICKNESS_M = 0.2` 的箱體,側面窄邊的 UV 不可被拉扯成條紋。
- **空場景**:只有地板無牆/柱時正常渲染。
- **與 VSM 陰影的互動**:normal map 可能與 VSM 的 `normalBias: 0.06` 產生互動(法線擾動影響陰影偏移),需確認貼牆家具的接觸陰影未因此重新出現漏光或 acne。
- **往返資源釋放**:程序化貼圖若用 canvas 產生,需確認 `THREE.Texture` 與底層 canvas 皆正確釋放。
